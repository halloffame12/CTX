# ctx Homebrew tap
#
# To use:
#   brew tap halloffame12/CTX
#   brew install ctx
#
# This repository contains the tap formula (Formulae/ctx.rb). It installs the
# prebuilt binary from GitHub Releases — no source compilation.
#
# To update the formula after a release:
#   scripts/update-homebrew.sh  or edit Formulae/ctx.rb with the new
#   version + sha256 from scripts/generate-checksums.sh.
