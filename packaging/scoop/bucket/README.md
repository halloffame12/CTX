# ctx Scoop bucket
#
# To use:
#   scoop bucket add ctx https://github.com/halloffame12/scoop-bucket
#   scoop install ctx
#
# This directory contains the manifest (bucket/ctx.json). The same manifest is
# mirrored at packaging/scoop/ctx.json in the main repository. It downloads
# the prebuilt ctx.exe from GitHub Releases with hash verification and
# autoupdate support.
